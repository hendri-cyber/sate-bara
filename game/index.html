SATE BARA — Charcoal Grill Rush. Masak sate di atas arang, layani pesanan sebelum pelanggan kehabisan sabar. Klik tusuk sate mentah untuk memanggang, ambil saat meteran hijau (gosong kalau kelamaan), susun di piring sesuai tiket, lalu bunyikan lonceng untuk mengantar. Keyboard: 1–8 bahan, Spasi antar, P jeda, R ulang, Tab ganti tiket.

Tidak ada permintaan jaringan: game ini berjalan sepenuhnya dari file lokal.
